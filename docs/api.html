API Reference

Base URL: https://auraops-backend-production.up.railway.app

All endpoints except /health and /api/v1/auth/* require Authorization: Bearer <token>.

Auth

MethodRouteDescription
POST/api/v1/auth/registerRegister, get API token
POST/api/v1/auth/loginLogin, get API token

Blueprint

MethodRouteDescription
POST/api/v1/blueprint/generateGenerate blueprint from manifest
GET/api/v1/blueprint/:idGet blueprint details

Deploy

MethodRouteDescription
POST/api/v1/deployDeploy agent to GPU
GET/api/v1/deployment/:idDeployment status
DELETE/api/v1/deployment/:idTerminate deployment
GET/api/v1/deployment/:id/logsContainer logs
GET/api/v1/agentsList running agents

POST /api/v1/deploy

{
  "blueprintId": "uuid",
  "blueprintJson": { ... },
  "lockfilePath": "/path/to/lock",
  "environmentHash": "sha256...",
  "gpuRequirements": {
    "minMemory": 16,
    "framework": "pytorch",
    "pythonVersion": "3.11"
  },
  "gpuCount": 1,
  "enableMcp": false
}

Response

{
  "success": true,
  "deploymentId": "uuid",
  "agentId": "uuid",
  "status": "running",
  "endpoint_url": "https://....modal.run",
  "deployTime": "4100ms"
}

Weights (SWR)

MethodRouteDescription
GET/api/v1/weightsList cached weights
GET/api/v1/weights/:hashWeight details
POST/api/v1/weights/pullQueue weight download
GET/api/v1/weights/statsCache statistics
