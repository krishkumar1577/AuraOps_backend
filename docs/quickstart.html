Quickstart

Deploy your first AI agent to a real GPU in under 90 seconds.

1. Install

npm install -g auraops

2. Register

curl -X POST https://auraops-backend-production.up.railway.app/api/v1/auth/register \
  -H "Content-Type: application/json" \
  -d '{"email":"you@example.com","password":"yourpassword"}'

Copy the token from the response.

3. Set your token

export AURAOPS_API_TOKEN=your_token_here

4. Deploy a Python file

auraops deploy my_agent.py

No requirements.txt needed. AuraOps scans your imports and infers the environment.

5. Check status

auraops status <deployment-id>

6. Hit your live endpoint

curl -X POST https://your-endpoint.modal.run \
  -H "Content-Type: application/json" \
  -d '{"input": "hello world"}'

Advanced options

# Multi-GPU
auraops deploy agent.py --gpus 4

# MCP server endpoint
auraops deploy agent.py --mcp

# Deploy entire crew
auraops deploy --fleet crew.yaml

# Initialize existing project
auraops init ./my-ml-project

Local development

git clone https://github.com/krishkumar1577/AuraOps_backend
cd AuraOps_backend
npm install
cp .env.example .env
npm run dev
